# 💼 Резюме — Высоцкая Виктория Анатольевна

Одностраничный сайт (landing page), представляющий профессиональное резюме специалиста с большим опытом в управлении, бухгалтерии и продажах.

## 📌 О проекте

Данный проект — это современный адаптивный лендинг, разработанный для презентации опыта, навыков и профессионального пути.

Сайт оформлен в минималистичном деловом стиле и подходит для:

* отправки работодателям
* публикации в интернете (например, через GitHub Pages)
* личного портфолио

---

## 🚀 Функционал

* 📱 Адаптивный дизайн (мобильные / планшеты / ПК)
* 🧑‍💼 Блок с основной информацией (Hero)
* 📖 Раздел "О себе"
* 🎓 Образование
* 💼 Опыт работы (структурированный таймлайн)
* 🛠 Навыки и личные качества
* 🖼 Галерея фотографий
* 📞 Контактная информация
* ✨ Плавные анимации появления
* 🎯 Hover-эффекты

---

## 🛠 Технологии

* HTML5
* CSS3 (Flexbox / Grid)
* JavaScript (минимально)
* Font Awesome (иконки)
* Lucide Icons (опционально)
* CDN-подключения (без сборки)
